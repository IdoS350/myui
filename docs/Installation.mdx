# Installation

myui components are distributed via the [shadcn](https://ui.shadcn.com) registry, make sure it's configured before proceeding.

## 1. Configure the `@/` alias

myui components use the `@/` path alias to reference shared utilities and other components after installation. This alias is a [shadcn requirement](https://ui.shadcn.com/docs/installation) and should already be present in your project.

**`tsconfig.json`**

```json
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

**`vite.config.ts`**

```ts
import path from 'path'

export default {
  resolve: {
    alias: { '@': path.resolve(__dirname, 'src') },
  },
}
```

## 3. Add the registry

Add the myui registry to your `components.json`:

```json
{
  "registries": {
    "@myui": "https://idos350.github.io/myui/r/{name}.json"
  }
}
```

## 4. Install a component

```bash
pnpm dlx shadcn@latest add @myui/<component-name>
```

## 5. Viewport meta (mobile keyboard support)

Components that anchor to the screen edge on mobile (e.g. [Drawer](?path=/docs/components-drawer--docs)) rely on `position: fixed` + `dvh`/`vh` sizing, which browsers compute against the layout viewport. By default that viewport stays static when the on-screen keyboard opens, so a fixed-position drawer can end up covered by the keyboard.

Add `interactive-widget=resizes-content` to your viewport `<meta>` tag so the layout viewport itself shrinks when the keyboard opens (Chrome 108+, Safari 17.4+):

```html
<meta
  name="viewport"
  content="width=device-width, initial-scale=1, interactive-widget=resizes-content"
/>
```
